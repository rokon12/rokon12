About

I'm A N M Bazlur Rahman, a Sr. Staff Software Engineer at Hammerspace based in Toronto. For more than fifteen years, I've been building, scaling, and debugging systems on the JVM, then turning those lessons into articles, conference talks, books, and community work.

I wrote Modern Concurrency in Java for O'Reilly Media, a practical guide to virtual threads, structured concurrency, and modern JVM concurrency patterns. In 2022, I was recognized as a Java Champion for contributions to the Java ecosystem and developer community.

I serve as editor for the Java Queue at InfoQ, write at Foojay, and publish The Coding Café, a newsletter on modern Java, concurrency, and AI-powered systems.

I've spoken at DevNexus, Devoxx Morocco, FOSDEM, ConFoo, GeeCON, JNation, JCon, Copenhagen Developers Festival, and many Java user groups. You can find recordings and session details on the talks page.

I founded the Java User Group in Bangladesh in 2013 and have published five Java books in Bengali, helping developers learn the platform in their own language.
